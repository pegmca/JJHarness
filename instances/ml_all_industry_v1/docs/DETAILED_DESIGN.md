# 系统详细设计方案 (Machine Learning Alpha - Final)

## 1. 目标
构建一个能够持续跑赢中证1000指数的机器学习模型。通过预测截面相对收益（Cross-sectional Relative Return）来捕捉领涨黑马。

## 2. 核心算法流程
*   **模型内核:** LightGBM Regression (rmse)。
*   **标注逻辑:** $Y = R_{stock} - Median(R_{market})$，预测未来 2 日收益。
*   **特征工程:**
    *   `price_std_score`: 价格对均线的乖离度（Z-Score）。
    *   `vol_spike`: 相对成交量倍数。
    *   `rsi_slope`: 动量加速度。
    *   `skewness`: 收益率分布偏度。
*   **换手控制 (The Buffer Logic):**
    *   持仓 Top 5。
    *   替换阈值 Top 3（即：只有更强的 Top 3 出现，才替换现有的 Top 5）。

## 3. 数据使用与权限策略
*   **日线/分钟线 (6个月窗口):** `2025-11-02` 至今。用于中长周期趋势识别、回测和策略稳定性验证。
*   **Tick (1周窗口):** `2026-04-24` 至今。仅用于极短线优化、盘口力量分析和入场价格优化。
*   **混合回测逻辑:** 
    1. 进行 **6个月** 的分钟级回测以验证策略基础收益。
    2. 进行 **1周** 的 Tick+分钟级联合回测，以验证高频过滤逻辑。
